# ETF-01. HAA — Hybrid Asset Allocation

- 보관일: 2026-09-28
- 저자: Wouter J. Keller, Jan Willem Keuning (2023, SSRN 4346906)
- 유형: ETF 자산배분 · 듀얼 모멘텀 + 경고 자산(canary) 1개 · 월 1회
- 한 줄: TIP(물가연동국채)의 모멘텀이 꺾이면 전부 방어로, 살아 있으면 8개 자산 중 강한 4개를 산다.

## 1. 구성 자산

| 역할 | 티커 | 비고 |
|---|---|---|
| 경고(canary) | TIP | 물가연동국채. 금리·인플레이션 상승 압력을 먼저 반영한다는 논리 |
| 공격 8개 | SPY, IWM, VEA, VWO, VNQ, DBC, IEF, TLT | 미국 대형·소형, 선진국, 신흥국, 리츠, 원자재, 중기·장기 국채 |
| 방어 2개 | BIL, IEF | 초단기 국채(현금 대용), 중기 국채 |

## 2. 모멘텀 계산 — 13612U

`모멘텀 = (1개월 수익률 + 3개월 + 6개월 + 12개월) / 4`

- 총수익(배당 포함) 기준, 가중치 없음(U = Unweighted)
- 매월 마지막 거래일 종가로 계산

## 3. 규칙 (매월 말)

1. **경고 확인:** TIP 모멘텀 ≤ 0 이면 → 방어 2개(BIL, IEF) 중 모멘텀이 높은 것 하나에 100%. 끝.
2. **공격 모드:** TIP 모멘텀 > 0 이면 → 공격 8개를 모멘텀 순으로 정렬, 상위 4개에 각 25%.
3. **개별 절대 모멘텀:** 상위 4개 중 모멘텀 ≤ 0인 자산의 몫(25%)은 BIL·IEF 중 나은 쪽으로 대체.
4. 다음 거래일 체결, 한 달 보유.

변형: HAA-Simple은 공격 자산을 SPY 하나로 둔다 (TIP 양수면 SPY, 음수면 BIL/IEF 중 택1).

## 4. 왜 반응형인가

- 보유 자산 자신의 추세(3단계)와 **외부 경고 자산**(1단계), 두 겹으로 반응한다.
- TIP은 금리 상승·인플레이션 국면에서 먼저 약해진다는 가정. 2022년처럼 주식·채권이 함께 빠지는 구간을 겨냥한 설계 (GEM이 2022년에 채권으로 피신했다가 크게 잃은 문제에 대한 답).

## 5. 성과

- 저자 백테스트: 1971~2022, 지수 연장 데이터. **거래비용·슬리피지·세금 제외**라고 저자가 명시.
- 발표 이후 검증 구간: 2023년~ 약 3년. 판단 불가.
- 제3자 추적: Allocate Smartly, TuringTrader, BestFolio.

## 6. 약점·확인할 점

- **단일 경고 자산 의존.** TIP 하나가 틀리면 전체가 틀린다. TIP 모멘텀이 0 근처에서 오가면 공격·방어를 반복하며 왕복 손실.
- 1~3개월 수익률이 섞여 있어 신호가 빠른 편 → 회전율 높음.
- 백테스트 시작점(1971)은 ETF가 없던 시기라 지수로 대체. TIP 자체도 1997년 출시 → 이전 구간은 추정치.
- 방어 자산에 IEF(중기채)가 있어 2022년형 채권 급락에 완전히 면역은 아님. BIL과의 모멘텀 비교가 이를 걸러 주는지가 관건.

## 7. 검증 시 합격 기준 (우리 구현이 맞는지)

- 2023~현재 월별 보유 종목이 Allocate Smartly / TuringTrader 공개 보유와 일치해야 함. 불일치 시 구현 오류.
- 2022년 구간을 별도로 보고, GEM(듀얼 모멘텀)과 낙폭 비교.
