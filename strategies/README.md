# 전략 후보 보관함

개별 트레이더·연구자의 공개된 매매 규칙을 후보별로 한 파일씩 보관한다.
목적은 "따라 하기"가 아니라 **규칙을 수치로 고정해 두고 나중에 같은 기준으로 검증**하기 위함이다.

**전체 요약·최종 추천·구현 순서는 [SUMMARY.md](SUMMARY.md) 참고.**

## 파일 규칙

- 파일명: `NN_이름_전략.md` (NN은 보관 순번)
- 각 파일은 같은 목차를 따른다: 출처 → 진입 → 보유 → 매도 → 사이징 → 자동화 가능 항목 → 비판 → 미정 파라미터
- "확인됨"은 1차 출처(저자 글·책·논문) 또는 복수 서평에서 교차 확인된 내용, "기억"은 책 내용에 대한 정리자의 기억이라 재확인이 필요한 내용

## 목록

범위: 반응형·추세추종만. **단기 평균회귀(코너스 RSI(2)·Double 7s, 벤스도프의 평균회귀 시스템 등)는 제외.**
