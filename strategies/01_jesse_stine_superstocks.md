# 01. 제시 스타인 (Jesse C. Stine) — Insider Buy Superstocks

- 보관일: 2026-09-28
- 유형: 미국 소형주 개별종목 · 실적+내부자+돌파 결합 · 재량 매매 체크리스트
- 결론 요약: 재료(각 신호)는 학술 근거가 있으나, 시스템이 아니라 재량 체크리스트. 150배의 원인은 종목 선택보다 집중·마진. 자동화는 스크리너(후보 발송)까지만. ETF 자산배분 반자동화가 안착한 뒤 위성 자금(전체 10% 이내)으로만 검토.

## 1. 출처

- 책: *Insider Buy Superstocks: The Super Laws of How I Turned $46K into $6.8 Million (14,972%) in 28 Months* (2013, 자가출판, ISBN 9780615818450)
- 주장 실적: 2003~2005년 28개월, 4만 6천 달러 → 680만 달러. 이후 실적은 공개돼 있지 않음
- 확인에 쓴 자료: 저자 미리보기 PDF(jessestine.com), Trading Skeptic·Stockopedia·Trading Reviewers 서평, Financial Wisdom TV·Moss Piglet 요약, TradingView 적용 예
- 참고: 30주선·바닥·거래량 개념은 스탠 와인스타인(Stage Analysis)과 윌리엄 오닐(CANSLIM)에서 온 것. 스타인의 추가분은 "내부자 매수 + 연환산 PER 10 이하 + 15달러 미만"의 결합

## 2. 진입 기준

### 2-1. 돌파 5조건 (확인됨 — 동시 충족)

| # | 조건 | 상세 |
|---|---|---|
| 1 | 주가 15달러 미만 | 최적 구간 4~15달러 |
| 2 | 강한 바닥(base) 돌파 | 길고 좁은 횡보일수록 좋음. 바닥 후반 주간 거래량이 직전 대상승기 최대치의 30~50%로 마름 |
| 3 | 30주 이동평균선 상향 돌파 | "역사상 대상승주의 90%가 대량거래 돌파 첫 주에 30주선 위로 올라섰거나 위에 있었다" |
| 4 | 막대한 주간 거래량 | 직전 몇 주 대비 확연히 큼. 구체 배수 미명시 |
| 5 | 가파른 상승 각도 | 돌파 주의 상승폭이 커야 함 |

### 2-2. 펀더멘털 (확인됨)

| 항목 | 기준 |
|---|---|
| 실적 | 블록버스터급이면서 지속 가능한 분기 실적. 높은 영업레버리지. 다음 분기 비교 기준(comps)이 낮을 것 |
| PER | 최신 분기 EPS×4 연환산 기준 10 이하. 저자는 PER 자체보다 "시장이 아직 반영 못 했다"는 증거로 사용 |
| 실적 일관성 | 최근 분기 매출·EPS가 들쭉날쭉하지 않을 것 |
| 부채 | 낮을 것 |
| 유통주식 | 1,000만 주 미만 |
| 시가총액 | 1억 달러 미만에서 출발 |
| 공매도 잔고 | 낮을 것 |
| 내부자 | 지분율 높고 공개시장 매수가 있을 것. 시장 무관심·약세 구간의 매수를 특히 중시 |
| 가산점 | 경쟁 적음, 애널리스트 커버리지 없음, 기억하기 쉬운 티커, 모멘텀 트레이더 유입 |

## 3. 보유 중 규칙 — 매직 라인

- 종목마다 상승 중 지지받는 특정 주간 이동평균선이 있음 (10·12·15·16주 등). (확인됨)
- 대부분 10~12주에 한 번은 매직 라인(대개 10주선)에 닿거나 옆으로 쉬며 선이 따라오길 기다림. 닿으면 대개 재상승 → 눌림 매수 지점. (확인됨)
- 매직 라인을 주봉 종가 기준으로 깨면 청산. (기억)

## 4. 매도 기준

| 신호 | 내용 | 상태 |
|---|---|---|
| 기록적 주간 변동폭 | 주봉이 최근 수십 주 중 가장 길고 이미 과열이면 매도 | 확인됨 |
| 30주선 과이격 | 30주선에서 너무 멀어졌을 때 매도 (저자 사례) | 확인됨 |
| 강할 때 판다 | 천장을 잡으려 하지 않고 강세에 분할 매도 | 확인됨 |
| 포물선형 급등 | 상승 각도가 수직에 가까워지면 분할 매도 | 기억 |
| 펀더멘털 신호 | 유상증자·전환사채, 애널리스트 첫 커버·언론 주목, 내부자 매도 전환 | 기억 |
| 손절 | 별도 % 손절보다 매직 라인 이탈이 기준 | 기억 |

## 5. 포지션 사이징 (확인됨)

- 가격·가치 괴리가 크다고 판단하면 순자산의 90% 이상을 1~2종목에 집중. 마진 사용.
- 저자 본인이 "대부분의 투자자에게 권하지 않는다"고 명시.
- 함의: 같은 선별 기준을 분산 포트폴리오로 쓰면 결과는 전혀 다른 숫자.

## 6. 반자동화로 옮길 때

| 자동 필터 (수치 고정 가능) | 사람 판단 (수치화 불가) |
|---|---|
| 주가 4~15달러, 시총 < 1억 달러, 유통주 < 1,000만 주 | 실적이 지속 가능한지, 일회성인지 |
| 최신 분기 EPS×4 기준 PER ≤ 10, 부채비율 상한 | 다음 분기 comps가 쉬운지 |
| 최근 N개월 내부자 공개시장 순매수 > 0 (SEC Form 4) | 매수 주체·규모의 의미 |
| 주가 > 30주선, 이번 주 거래량 > 직전 K주 평균 × M배 | 바닥이 "조용했는지", 돌파 각도 |
| 직전 N주 가격 변동폭이 좁음 (바닥 대용) | 매직 라인이 몇 주선인지 |

발송 형식: 종목별 체크리스트(통과 항목 ✓, 수치, 차트 링크). 기계는 "조건 충족"만 알리고 매수 신호는 내지 않는다.

## 7. 비판점

- 표본 1명, 28개월, 2003~2005 소형주 강세장. 출판(2013) 이후 실적 없음.
- 사례 차트가 사후 선택이라는 서평 지적. 실패 사례 부재.
- 유통주 1,000만 주 미만은 유동성 부족 → 자동 주문·손절과 가장 안 맞음. 한국 시장 이식 시 거래정지·관리종목 리스크 추가.
- 반응형 추세추종 ETF 자산배분(현재 1순위 목표)과는 원리·대상·판단 방식이 모두 다름.
