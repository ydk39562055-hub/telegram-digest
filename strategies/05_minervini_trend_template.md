# 05. 마크 미너비니 (Mark Minervini) — 트렌드 템플릿 + SEPA/VCP

- 보관일: 2026-09-28
- 출처: *Trade Like a Stock Market Wizard* (2013), *Think & Trade Like a Champion* (2017)
- 유형: 미국 성장주 · 일봉 · **필터는 자동, 진입(VCP)은 재량** · 롱 온리
- 실적: US Investing Championship 1997년 155%, 2021년 334% (제3자 대회)
- 한 줄: 이동평균이 위에서부터 50 > 150 > 200일 순으로 정렬된 "2단계 상승" 종목만 보고, 그중 변동폭이 점점 줄어드는 바닥에서 돌파할 때 산다.

## A. 트렌드 템플릿 8조건 (확인됨 — 전부 동시 충족)

| # | 조건 |
|---|---|
| 1 | 주가 > 150일선, 주가 > 200일선 |
| 2 | 150일선 > 200일선 |
| 3 | 200일선이 최소 1개월 상승 중 (가능하면 4~5개월) |
| 4 | 50일선 > 150일선, 50일선 > 200일선 |
| 5 | 주가 > 50일선 |
| 6 | 주가 ≥ 52주 최저가 × 1.25 (책에 따라 1.30) |
| 7 | 주가 ≥ 52주 최고가 × 0.75 (신고가에 가까울수록 좋음) |
| 8 | 상대강도(RS) 순위 ≥ 70 (가능하면 85~90 이상) |

→ 전부 수치라 **완전 자동 스크리닝 가능.**

## B. 진입 — VCP (변동성 수축 패턴) — 재량

| 항목 | 내용 |
|---|---|
| 형태 | 2단계 상승 중 바닥에서 조정폭이 2~6회에 걸쳐 점점 작아짐 (예: 25% → 12% → 6%) |
| 거래량 | 마지막 수축 구간에서 거래량 감소 |
| 매수 | 피벗(마지막 수축의 고점) 돌파 + 거래량 증가 |
| 추격 금지 | 피벗 대비 +5% 이내에서만 매수 |
| 손절 | 마지막 수축 저점 바로 아래. 통상 진입가 −7~8% 이내 |
| 비중 | 시험 매수(pilot) 후 예상대로 움직이면 추가. 1회 손실은 계좌의 작은 비율로 제한 |

## 특징

- 스타인(01)·와인스타인(06)과 같은 계열이지만 **"2단계 판정"을 8개 숫자로 고정**했다는 점이 핵심 기여.
- 자동화 관점: 템플릿 = 1차 필터(자동), VCP = 사람이 차트를 보고 판단. 반자동화 구조에 가장 잘 맞음.

## 성과

- 본인 백테스트 공개 없음. 대회 실적은 집중 투자·재량 결과라 시스템 성과로 볼 수 없음.
- SiamQuant(태국) 연구: 단순 돌파 시스템에 템플릿 필터를 씌우면 **최대낙폭이 유의미하게 감소**. 필터로서의 가치는 확인.

## 약점

- VCP 판정이 주관적 → 자동화하면 "우리가 만든 VCP 정의"가 됨.
- 7~8% 손절 + 낮은 승률 조합이라 연속 손절 구간이 길 수 있음.
- 템플릿 통과 종목 수가 강세장엔 수백 개, 약세장엔 거의 0 → 후보 수 자체가 시장 온도계 역할 (반응형으로 활용 가능).
