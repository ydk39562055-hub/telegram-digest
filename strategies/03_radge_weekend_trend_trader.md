# 03. 닉 라지 (Nick Radge) — Weekend Trend Trader

- 보관일: 2026-09-28
- 출처: *Weekend Trend Trader* (2013). 저자는 호주 The Chartist 대표. 관련 저서 *Unholy Grails* (2012)
- 유형: 미국 개별주 · 주봉 · 완전 자동 · 롱 온리 돌파 추세
- 한 줄: 20주 신고가를 뚫고 20주간 30% 넘게 오른 종목을 사고, 시장이 좋으면 넓게(40%), 나빠지면 좁게(10%) 추적손절한다.

## 규칙 (확인됨)

| 항목 | 규칙 |
|---|---|
| 주기 | 주 1회. 주말에 계산, 월요일 시가 체결 |
| 시장 필터 (진입) | 지수(원문 S&P 500 / 소형주 버전은 Russell) 종가 > 20주 이동평균 |
| 종목 조건 1 | 이번 주 종가가 **20주 신고가** |
| 종목 조건 2 | **20주 수익률(ROC 20) > 30%** |
| 목표 보유 수 | 20종목 (동일 비중 5%) |
| 청산 — 시장 양호 | 지수 10주 추세가 상승이면: 주간 종가 기준 **고점 대비 40% 하락** 시 매도 |
| 청산 — 시장 악화 | 지수 10주 추세가 하락으로 바뀌면: 추적손절을 **고점 대비 10%로 조임** |

## 왜 반응형인가

- 시장 상태에 따라 **청산 규칙 자체가 바뀜.** 평소엔 넓은 손절로 큰 추세를 끝까지 타고, 시장이 꺾이면 손절을 좁혀 빠르게 빠져나옴. 이번 목록에서 "반응형 청산"을 가장 명시적으로 구현한 전략.

## 성과

- 1995~2012 Russell 3000(소형주 포함): **MAR(CAGR ÷ 최대낙폭) 1.16** (NeuroQuant 인용)
- QuantifiedStrategies 재현: 연 약 22%
- 독립 구현: GitHub `laffuste/weekend-backtrader`, AmiBroker 포럼, ThinkScript

## 약점

- 40% 추적손절은 매우 넓음 → 한 종목이 고점에서 40% 빠질 때까지 보유. 개별 손실이 크고 심리적으로 버티기 어려움.
- 신규 진입 조건이 까다로워 약세장 후 초기 반등에서는 후보가 적음.
- 소형주 유니버스는 생존편향·유동성 문제. 상장폐지 종목 포함 데이터 필요.
- 승률은 낮은 편(추세추종 전형, 40% 안팎 예상).

## 미정 파라미터

| 파라미터 | 비고 |
|---|---|
| 유니버스 | 원문 기본은 미국 전체. 최소 가격·거래대금 하한은 책 확인 필요 |
| 20종목 초과 후보 시 우선순위 | 책 확인 필요 (ROC 순 등) |
